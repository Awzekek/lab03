# Лабораторная работа №3 — Анализ и моделирование данных

**Предметная область:** Aviasales — сервис бронирования авиабилетов  
**Вариант:** 10

## Цель работы

Проанализировать предметную область, выделить основные объекты данных и их атрибуты, определить типы данных и связи между объектами, а также построить концептуальную ER-модель.

## Содержание проекта

* `report/analysis.md` — полный отчёт по лабораторной работе.
* `diagrams/er\_diagram.drawio` — исходник ER-диаграммы, созданной в draw.io.
* `images/er\_diagram.png` — экспортированное изображение ER-диаграммы.

## Результат

В ходе работы выполнен анализ предметной области Aviasales, определены основные сущности, их атрибуты и взаимосвязи. Построена концептуальная модель данных.

Реализация базы данных в рамках лабораторной работы не требуется.
